# GitHub

Usa `github` como identificador del perfil.

- GitHub aloja el código y los pull requests.
- Usa las herramientas de PR de T3 Code cuando el host las indique. En una sesión de terminal, usa `gh`.
- Si el proyecto usa GitHub Issues y el cambio tiene un issue asociado, vincúlalo con el pull request.
- Guarda en el `AGENTS.md` del proyecto (puedes partir desde [la plantilla](../../skills/install/references/agents-template.md)) la rama de destino, los tableros/filtros de issues, el techo de autonomía, los checks y la política de publicación. Consulta las referencias de [triage](../../skills/triage/references/github.md), [assume-task](../../skills/assume-task/references/github.md), [open-pr](../../skills/open-pr/references/github.md) y [babysit-pr](../../skills/babysit-pr/references/github.md) para esta plataforma.
