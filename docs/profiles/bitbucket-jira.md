# Bitbucket + Jira

Usa `bitbucket-jira` como identificador del perfil.

- Bitbucket aloja el código y los pull requests.
- Jira lleva los tickets. Si un cambio tiene ticket, usa su clave al vincularlo con el pull request.
- Usa `twg` para las operaciones de Bitbucket y Jira. Las referencias de [triage](../../skills/triage/references/bitbucket-jira.md), [assume-task](../../skills/assume-task/references/bitbucket-jira.md), [open-pr](../../skills/open-pr/references/bitbucket-jira.md) y [babysit-pr](../../skills/babysit-pr/references/bitbucket-jira.md) documentan el flujo de esta plataforma.
- Deja en el `AGENTS.md` del proyecto (puedes partir desde [la plantilla](../../skills/ayanostack/references/agents-template.md)) sus tableros/queries, permisos de escritura en Jira, techo de autonomía, ramas, checks obligatorios, bots de revisión y convenciones de tickets. Un watcher privado puede declararse ahí.
